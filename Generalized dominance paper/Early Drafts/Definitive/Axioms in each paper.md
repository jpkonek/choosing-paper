# Axioms and hypotheses in the two definitive papers (26 October 2026)

This list uses the current manuscripts' numbering. Each paper's material falls into four kinds:
- **(A)** the standing setting;
- **(B)** conditions placed on rankings;
- **(C)** hypotheses of particular theorems;
- **(D)** properties that are proved, not assumed. These are listed so they cannot be mistaken for axioms.

---

## Coherence and Dominance under General Rankings (LDG)

### A. Standing setting (§2)
- Worlds Ω: any nonempty set, with no structure.
- Models: any nonempty set, with no structure.
- A ranking L: an evaluation domain M_L, and one binary relation ⪯_ω per world.
  - **No property of the relations is assumed:** not reflexivity, transitivity or completeness.
- The coherent class C is fixed in advance, independently of the rankings.

### B. Conditions on a single ranking (each used only where stated)
1. **Closure under ties.** A model tied at every world with an undominated coherent model is itself an undominated coherent model.
   - Used in: Thm 3.2 (last claim), Thm 4.1(c), Prop 6.1(a), Prop 6.5(b).
   - Needed only to identify the undominated models *exactly*, not to obtain dominators.
2. **Preorder (reflexive and transitive).** Used only in Prop 6.3 and Prop 6.5(c).
3. **Completeness.** Used only through loss rankings, which are complete (Lemma 2.1 converse, Lemma 2.3).

### C. Hypotheses that derive dominance (each theorem separately)
- **Thm 3.2** (finite Ω, ranking generated by a loss). Each prior p is assigned an undominated coherent model c_p such that:
  - (i) *Bayes choice*: c_p is a Bayes model for some prior supported within supp p;
  - (ii) *lower semicontinuity*: p ↦ L(c_p, ω) is lower semicontinuous at each world.
- **Thm 3.3** (any Ω, loss ranking). There is a compact space Θ with undominated coherent models c_θ, such that:
  - (i) θ ↦ L(c_θ, ω) is lower semicontinuous;
  - (ii) on cofinally many finite sets of worlds there are *continuous* maps from the simplex to Θ that make Bayes choices.
- **Thm 4.1** (finite Ω, any ranking). One undominated coherent model c_p is assigned to each prior, the same against every rival. Each rival and world has a closed set A_ω(m) of priors such that:
  - (i) *guarantee*: c_p ⪯_ω m on A_ω(m);
  - (ii) *serving condition*: every prior lies in A_ω(m) for some world it charges.

  This weakens the selection argument: only closed *subsets* of the comparison sets are needed.
- **Cor 4.2** (the selection argument itself). Each assigned model is competitive on supp p, and each full comparison set {p : c_p ⪯_ω m} is closed.
- **Thm 4.6** (any Ω, any ranking).
  1. A compact family of undominated coherent models c_θ, with closed guaranteed-comparison sets K_ω(m) ⊆ Θ.
  2. On cofinally many finite sets F there is a map θ_F from the simplex to Θ, not necessarily continuous and the same against every rival. Its closed local guarantee sets A^F_ω(m) satisfy:
     - (a) local ⊆ global;
     - (b) the serving condition.
- **§5 (margins, Bayes models, strict dominance).** These use the hypotheses of Thm 3.3. **Prop 5.3** adds upper semicontinuity of V, obtained either from (a) finite losses of the assigned models, or from (b) V finite, c_p Bayes for p, and continuous losses.

### C′. Constructing rankings (Prop 7.1)
- *Data*:
  - a "change" for each ordered pair, null only on the diagonal;
  - "available to z";
  - for each world, a set of guided changes that contains the null change;
  - for each world, a real score.
- *Conditions*:
  - **guided changes improve the score** (for part (a));
  - **guidance protects coherent models** (for part (b)).
- *Part (c)* is an equivalence: the dominance property holds iff the specific improvements exist. It assumes neither.

### C″. Rational permissibility (§6.3): the normative premises
- **Dominance principle** (a definition). A model is irrational if every ranking in the family that evaluates it has an undominated model dominating it. It is permissible if it is undominated under some ranking.
- **Evaluability.** Every model is evaluated by some ranking. No proof uses it; it prevents vacuous verdicts.
- **Coherent admissibility.** Every coherent model is an undominated coherent model of some ranking in the family.
- Each ranking is closed under ties, or is a preorder.
- Each ranking has the dominance property, **established by the theorems above or by other means**.

### C‴. Applications (§8): extra hypotheses
- **Prop 8.1** (finite Ω, C = Δ ⊆ M_L).
  - Lower semicontinuity in p, and strict propriety relative to M_L.
  - Uniqueness of Bayes models gives exact identification.
  - Finite losses or continuity give uniform dominance.
- **Thm 8.2** (probabilism on arbitrary domains).
  - Quasi-strict propriety, and lower semicontinuity on C at each world.
  - Bounded losses give uniform dominance.
- **Prop 8.4** (conditional reports).
  - Block propriety, and lower semicontinuity along coherent systems.
  - Unique minimisers give exact identification.
- **Prop 8.6.** A specific Brier example on ℕ, with no extra hypotheses.
- **Prop 8.7.** A counterexample: a truth-directed loss under which coherent admissibility holds but dominance fails.

### D. Proved, never assumed
- **The dominance property:** every evaluable model is weakly dominated by an undominated coherent model. Thms 3.2, 3.3, 4.1 and 4.6 derive it, and Prop 7.1(c) reduces it to the existence of improvements.

## Coherence and accuracy for sets of desirable gambles (application)

### A. Standing setting (§2)
- **Worlds.** Ω is any nonempty set.
- **Gambles.**
  - E ⊆ ℓ∞(Ω) is a norm-closed linear subspace.
  - **Separable.**
  - **Contains 1**, or any gamble bounded below by a positive constant (Remark B.3).
- **States.** Positive, normalised linear functionals on E. A **credal set** is a nonempty, weak-* closed, convex set of states.
- **Measure.** A finite Borel measure μ on E, with:
  - **(M1)** finite first moment, ∫‖h‖ dμ < ∞. Assumed throughout.
  - **(M2)** null indifference boundaries, μ{P_Q = 0} = 0 for every credal set Q. Used for:
    - the minimax lemma and the repair theorem;
    - protection of coherent models;
    - identifying coherent sets of desirable gambles with coherent models.
    - Essential (Example B.2).
  - **(M3)** full support. Used only to make Q ↦ D_Q one-to-one (the bijection in Thm 6.8(a)), and for local freedom on one-sided domains (Appendix C).
- **Models.** Completion-measurable subsets of E, identified up to μ-null sets. A model is coherent iff it equals D_Q a.e. for a credal set Q.
- **Score.** m_ω(X) = ∫_X h(ω) dμ, the integrated payoff. Higher is better.

### B. The ranking (Definition 6.1): a definition, not axioms
At each world, X ⪯_ω Y iff the change from Y to X:
- (i) is guided by ω, meaning it adds only gambles that pay off at ω and removes only gambles that lose at ω; or
- (ii) could be made by no coherent model and strictly raises m_ω.

**Characterisation (Prop 6.3).** For the fixed score, ⪯_ω is the largest relation such that:
1. every comparison guided by ω is accepted;
2. every accepted comparison between distinct models strictly raises the score;
3. a change that some coherent model could make is accepted only when it is guided.

Condition 3 is the substantive assumption. It restricts individual comparisons at individual worlds, which is stronger than coherent admissibility, and its independent justification is open (§9.2).

### C. What "covers K" requires (§6.3)
A *ranking on a domain U* is, by definition, a reflexive relation per world under which a.e.-equal models are tied. The requirements:
- **On the ranking:**
  - (1) strict guidance;
  - independence (comparisons depend only on the change);
  - acyclicity: no chain of weak comparisons ends in a strict reversal. Ties are allowed.
- **The dominance requirements (what must be achieved; proved, not assumed, for Definition 6.1):**
  - (2) global coherence;
  - (3) closure under ties;
  - (4) D_K is a model on U and is undominated;
  - (5) incoherent-model dominance.
- **On the domain:**
  - (6) local freedom at D_K.

### C′. Restricted domains (Cor 7.1)
- U is **closed under coherent hulls**: hull(B) ⊆ U a.e. for every consistent B ⊆ U.

### C″. Structured example (Thm 8.1)
- Finitely many worlds, E = ℝⁿ.
- μ has Lebesgue's null sets and a finite first moment.
- p ∈ relint Δ, 0 < ε ≤ 1, domain {p·h > 0}.
- The veto–Brier ranking is lexicographic, complete and transitive.

### D. Proved, never assumed
- **Repair theorem (Thm 5.1)**, under (M1) and (M2).
- **Properties of the ranking (Prop 6.2):**
  - reflexivity and independence;
  - strict guidance;
  - every accepted distinct comparison strictly raises the score;
  - no ties between distinct models;
  - acyclicity;
  - disjoint additivity.
- **Protection (Prop 6.6)** and **dominance is always strict (Prop 6.7)**, under (M2).
- **Coverage (Thm 6.8):**
  - undominated = coherent;
  - uniform dominance of every incoherent model;
  - every credal set covered on E.
- **Shown not to hold:** the ranking is in general **not** transitive and **not** complete (Example 6.4).

### Not used anywhere in the main results
- Transitivity, completeness, Bayes choice, compact families and the selection argument.
- Lyapunov's theorem (it appears only in the veto–Brier appendix).

## Cross-paper mismatches found while compiling this list
1. **Reflexivity.** LDG assumes nothing about the relations, not even reflexivity. The application paper builds reflexivity, and "a.e.-equal models tied", into its definition of a ranking on a domain. The difference is harmless, since the application's own ranking is proved reflexive, but the two papers should say the same thing, or the application should say why it adds this.
2. **"Dominance property".** In LDG it means "every evaluable model is weakly dominated by an undominated coherent model" (the application's Thm 6.8(c)). The application uses the phrase for its whole list (2)–(5), which also includes closure under ties and the target. One paper should rename. Suggestion: the application calls (2)–(5) "the dominance requirements" and keeps "dominance property" in LDG's sense.
