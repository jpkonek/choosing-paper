Loss Relations convention (project doc claude/loss-relations-sdg.tex):
A set D is a coherent set of desirable gambles if (D1) 0 ∉ D; (D2) g ⪈ 0 ⇒ g ∈ D; (D3) g ∈ D, λ>0 ⇒ λg ∈ D; (D4) g,h ∈ D ⇒ g+h ∈ D.
A model X is coherent if X ≈ D (a.e. equal) for some coherent set of desirable gambles D.
D_K := {φ_K > 0} ∪ {g ⪈ 0}.
