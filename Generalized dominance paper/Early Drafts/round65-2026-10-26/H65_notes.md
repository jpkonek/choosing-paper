## 0. Verdict in plain English

**(H) holds for every incoherent model, in any number of worlds, under the setting of BRIEF65.** This is success criterion (A). The proof is in §2. It is short and elementary.

The defender is always of one explicit form:

> N = hull(X) ∩ {π·h > 0} ∩ (at most 2n thin half-space cuts).

It has a **strict margin in every coordinate**: m(N) − m(X) ≫ 0. So it also answers the question WT65 left open (§4).

The idea has two parts.

1. **Dominate from inside the hull.** Apply ES64's Lemma 5.1 with the domain U replaced by G := hull(X). Since G is itself a coherent cone, the "G-Bayes acts" G ∩ {π·h > 0} are coherent. X is not one of them, because X is incoherent. So some G-Bayes act N₀ strictly dominates X in every coordinate.
2. **The hull of X is generated by support points of X that the defender does not contain.**
   - Every point of N₀ lies in the open cone generated by ℝⁿ₊ and those support points of X that are *not* inside N₀ (the Generation Lemma, §2.3).
   - In the pointed case these are the extreme rays of the hull. They lie on ∂G, so they are outside the open set N₀ or on its boundary.
   - Points on the boundary can be cut away from N₀ by a thin wedge. The cost of the wedge tends to 0, so the cuts are paid for by N₀'s strict margin.
   - After the cuts, these support points are support points of the *removed* part X∖N. So every gap point of N∖X lies in hull(X∖N), and the gap N∖X is non-null.

**Why the earlier attempts stalled.** ES64 and REF64 started from Bayes acts of U, which can stick out of hull(X), and cut only along the faces of U. Support points of X deep inside such a defender cannot be removed cheaply. The restriction that caused the failures was therefore **using U-Bayes acts (and U-face cuts) as the base defender**. Relativising to hull(X) removes the problem.

## 1. Setting and notation

- n ≥ 1 worlds.
- (M): μ is a finite Borel measure on ℝⁿ with the same null sets as Lebesgue measure, and ∫|h| dμ < ∞. A positive density with a finite first moment is a special case.
- K′ ⊆ relint Δ is nonempty, compact and convex. U := D_{K′}.
- For S ⊆ Δ: D_S := {h : q·h > 0 ∀q ∈ S} and P_S(h) := inf_{q∈S} q·h.
- Models are measurable X ⊆ U, modulo null sets. A model is **coherent** if X = D_Q a.e. for some compact convex Q with K′ ⊆ Q ⊆ Δ.
- m(X) := ∫_X h dμ.
- Q_B := {q ∈ Δ : q·h ≥ 0 for μ-a.e. h ∈ B}, and hull(B) := D_{Q_B}. For B ⊆ U, K′ ⊆ Q_B, so hull(B) is a coherent model.
- **(H):** every incoherent X has a coherent N with m(N) ≥ m(X), m(N) ≠ m(X), and μ((N∖X) ∩ hull(X∖N)) > 0.

**Supports.**
- An *open cone* is an open set V ≠ ∅ with tV = V for all t > 0.
- The **conic support** of a measurable E is Σ(E) := {0} ∪ {h ≠ 0 : μ(E ∩ V) > 0 for every open cone V ∋ h}. It is a closed cone: its complement is a union of open cones.
- The **support** of E is supp(E) := {h : μ(E ∩ V) > 0 for every open V ∋ h}. Under (M), a.e. point of E lies in supp(E), by the Lebesgue density theorem.

## 2. The theorem and its proof

**Theorem H (PROVED).** Assume (M) and K′ ⊆ relint Δ nonempty, compact and convex. Let X ⊆ U be an incoherent model. Then there is a compact convex Q with K′ ⊆ Q ⊆ Δ such that N := D_Q satisfies:
- **(i)** m(N) − m(X) ∈ int ℝⁿ₊ (strict margin in every coordinate);
- **(ii)** there are a ∈ supp(N∖X) ∩ N, points e₁, …, e_r ∈ Σ(X∖N) with r ≤ n, and λ_j ≥ 0, such that a − Σ_j λ_j e_j ∈ int ℝⁿ₊;
- **(iii)** hence μ((N∖X) ∩ hull(X∖N)) > 0.

Moreover, Q = conv(Q_X ∪ {π} ∪ {q′₁, …, q′_m}) with m ≤ 2n. So N is hull(X) ∩ {π·h > 0} with at most 2n further half-space cuts. If cl hull(X) contains no line, which always holds when dim K′ = n−1, then m ≤ n.

The proof uses six lemmas. Only Lemma 2.2 depends on Lyapunov's theorem, and it is ES64's refereed Lemma 5.1 with U replaced by G.

### 2.1 Lemma 2.1 (sufficiency of a support witness; PROVED)

Let A, B ⊆ U be measurable. Suppose a ∈ supp(A), e₁, …, e_r ∈ Σ(B), λ_j ≥ 0, and p := a − Σλ_j e_j ∈ int ℝⁿ₊. Then μ(A ∩ hull(B)) > 0.

*Proof.*
- **Each q ∈ Q_B is non-negative on each e_j.** Suppose q·e_j < 0. Then V := {q·h < 0} is an open cone containing e_j, so μ(B ∩ V) > 0, contradicting q ∈ Q_B.
- **A uniform margin at a.** Put η := min_i p_i > 0. For q ∈ Q_B ⊆ Δ, q·a = Σλ_j q·e_j + q·p ≥ η.
- **A neighbourhood of a lies in the hull.** If |h − a|_∞ < η, then q·h ≥ q·a − |h−a|_∞ > 0 for every q ∈ Q_B. So h ∈ D_{Q_B} = hull(B).
- **Conclusion.** Since a ∈ supp(A), μ(A ∩ {|h − a|_∞ < η}) > 0. ∎

This is the sufficiency half of the auditor's witness, with support points in place of density points. WT65's Lemma W1 gives the converse. Theorem H does not need the converse.

### 2.2 Lemma 2.2 (the hull of X; strict domination from inside it; PROVED)

Let X be a model. Put Σ := Σ(X), C := cl cone(Σ ∪ ℝⁿ₊) and G := hull(X).

- **(a)** Q_X = {q ∈ Δ : q·σ ≥ 0 ∀σ ∈ Σ}.
- **(b)** G = int C, and cl G = C.
- **(c)** X ⊆ G a.e.
- **(d)** If X is incoherent, there is π ∈ Δ with m(G ∩ {π·h > 0}) − m(X) ∈ int ℝⁿ₊.

*Proof of (a).*
- (⊆) If q ∈ Q_X and q·σ < 0 for some σ ∈ Σ, then {q·h < 0} is an open cone around σ, so it has positive X-measure. This is a contradiction.
- (⊇) Let q ≥ 0 on Σ. Every h with q·h < 0 lies outside Σ, so it has an open cone V_h ∋ h with μ(X ∩ V_h) = 0. By Lindelöf, countably many V_h cover {q·h < 0}. So μ(X ∩ {q·h < 0}) = 0.

*Proof of (b).*
- C is a closed convex cone with C ⊇ ℝⁿ₊, so int C ≠ ∅.
- C* := {y : y·c ≥ 0 ∀c ∈ C} ⊆ ℝⁿ₊. By (a), every nonzero y ∈ C* is a positive multiple of an element of Q_X, and conversely.
- **Standard fact, proved here.** int C = {h : y·h > 0 ∀y ∈ C*∖0}.
  - (⊆) If h ∈ int C and y ∈ C*∖0, then h − εy ∈ C for small ε, so y·h ≥ ε|y|² > 0.
  - (⊇) If h ∉ int C, separate h from the open convex set int C. This gives y ≠ 0 with y·h ≤ y·c for all c ∈ int C, hence for all c ∈ C = cl int C. Since C is a cone, y ∈ C* and y·h ≤ 0.
- So int C = D_{Q_X} = G. Also cl int C = C for a convex set with nonempty interior.

*Proof of (c).*
- ∂C is μ-null, as the boundary of a convex set (WT65 C2(b) gives another proof).
- ℝⁿ∖C = ∪_{q∈Q_X} {q·h < 0}. This is an open cover; by Lindelöf it has a countable subcover. Each X ∩ {q·h < 0} is null, by the definition of Q_X.
- So X ∖ G ⊆ (X∖C) ∪ ∂C is null.

*Proof of (d).* This is ES64's Lemma 5.1 (refereed CORRECT, REF64_es E22) with U replaced by G. Here is the argument and what changes.
- Put ℳ_G := {m(Y) : Y ⊆ G measurable}.
- **ℳ_G is compact and convex.** The vector measure Y ↦ ∫_Y h dμ is finite (finite first moment) and non-atomic (by (M)). Lyapunov's theorem applies.
- **ℳ_G is full-dimensional.** If ℳ_G lay in a hyperplane {y : ν·y = c}, then c = 0 because ∅ ⊆ G. So ∫_Y ν·h dμ = 0 for all Y ⊆ G, hence ν·h = 0 μ-a.e. on the non-empty open set G. By (M) this forces ν = 0.
- **Unique maximisers.** For every ν ≠ 0, the maximisers of ν·m(Y) over Y ⊆ G are a.e. equal to G ∩ {ν·h > 0}, because {ν·h = 0} is null.
- **X is not a G-Bayes act.** By (c), X is a candidate Y. For ν ∈ ℝⁿ₊∖0, G ∩ {ν·h > 0} = D_{conv(Q_X ∪ {ν/|ν|₁})}. This is coherent, since K′ ⊆ Q_X. So X, which is incoherent, is not a.e. of this form.
- ES64's interior and boundary cases now go through verbatim with U replaced by G. They use exactly the three facts above.
  - The boundary case: an outer normal ν ≥ 0 at m(X) would make X = G ∩ {ν·h > 0}, a G-Bayes act.
  - Otherwise the normal cone is pointed and misses ℝⁿ₊∖0. Separation yields d ≫ 0 in the interior of the tangent cone, and the interior case applies.
- The output is λ ∈ ℝⁿ₊∖0 and π := λ/|λ|₁ with m(G ∩ {π·h > 0}) ≥ m(X) + ε𝟙. ∎

### 2.3 Lemma 2.3 (Generation Lemma; PROVED)

Let:
- C ⊆ ℝⁿ be a closed convex cone with ℝⁿ₊ ⊆ C, and L := C ∩ (−C) its lineality space;
- Σ ⊆ C be a closed cone with C = cl cone(Σ ∪ ℝⁿ₊);
- N₁ ⊆ C be an open convex cone with int ℝⁿ₊ ⊆ N₁ and cl N₁ ∩ L = {0}.

Then

  **N₁ ⊆ cone(Σ ∖ N₁) + int ℝⁿ₊.**

Here cone(·) means finite non-negative combinations.

In words: every point of N₁ is a non-negative combination of points of Σ lying outside N₁, plus a strictly positive vector.

*Proof.* Put P := cl N₁ ⊆ C, T := Σ ∖ N₁ (a closed cone), and C_out := cl cone(T ∪ ℝⁿ₊).

- **Step 0: P ∩ (−C) = {0}.** If x ∈ P and −x ∈ C, then x ∈ C ∩ −C = L, so x ∈ P ∩ L = {0}. In particular P is pointed, and P ∩ (−C_out) = {0}.
- **Step 1: a functional g with g > 0 on P∖0 and g ≥ 0 on C_out.**
  - S_P := conv(P ∩ {|h|₂ = 1}) is compact, lies in P, and misses 0 because P is pointed.
  - S_P misses the closed convex cone −C_out, by Step 0.
  - Strict separation gives g and α with g·x > α ≥ g·y for x ∈ S_P and y ∈ −C_out. Since −C_out is a cone containing 0, α ≥ 0 and g ≤ 0 on −C_out.
- **Step 2: C = P′ + C_out, where P′ := cl cone(Σ ∩ P).**
  - cone(Σ ∪ ℝⁿ₊) ⊆ cone(Σ ∩ N₁) + cone(T ∪ ℝⁿ₊) ⊆ P′ + C_out.
  - P′ + C_out is closed. Suppose y_k + z_k → w with y_k ∈ P′ and z_k ∈ C_out. If |y_k| → ∞ along a subsequence, then y_k/|y_k| → ȳ ∈ P′ with |ȳ| = 1 and z_k/|y_k| → −ȳ ∈ C_out. This contradicts Step 0. So y_k is bounded, and limits of subsequences give w ∈ P′ + C_out.
  - Taking closures, C ⊆ P′ + C_out ⊆ C.
- **Step 3: P ⊆ C_out.** Suppose x ∈ P ∖ C_out.
  - Separate x from the closed convex cone C_out: there is q with q·x < 0 ≤ q·c for all c ∈ C_out. Since ℝⁿ₊ ⊆ C_out, q ∈ ℝⁿ₊∖0.
  - By Step 2, x = y + z with y ∈ P′ and z ∈ C_out. So q·y ≤ q·x < 0, and some t ∈ Σ ∩ P has q·t < 0.
  - The set Σ ∩ P ∩ {g = 1} is compact (g ≥ c > 0 on P ∩ sphere) and contains a multiple of t. Let t* minimise q on it, with value −β < 0.
  - Then q·s + β g(s) ≥ 0 for all s ∈ Σ ∩ P, hence for all s ∈ P′ by linearity and closure.
  - t* ∉ T, since q ≥ 0 on T ⊆ C_out. So t* ∈ N₁, which is open.
  - Pick x₀ ∈ int ℝⁿ₊ ⊆ N₁. For small ε > 0, w := t* − εx₀ ∈ N₁ ⊆ C. By Step 2, w = y + z with y ∈ P′ and z ∈ C_out. Then:
    - q·y ≤ q·w = −β − ε q·x₀ < −β;
    - 0 ≤ g(y) ≤ g(w) = 1 − ε g(x₀) < 1.
  - But q·y ≥ −β g(y) ≥ −β, since 0 ≤ g(y) ≤ 1. This is a contradiction.
- **Step 4: from P ⊆ C_out to the claim.** N₁ = int P ⊆ int C_out. Let x ∈ int C_out. Then x − ε𝟙 ∈ C_out = cl K, with K := cone(T) + ℝⁿ₊, for some ε > 0. Pick k ∈ K with |x − ε𝟙 − k|_∞ < ε/2. Then x = k + [x − k], where x − k ≥ (ε/2)𝟙 ≫ 0. So x ∈ cone(T) + int ℝⁿ₊. ∎

*Remarks.*
- **The pointed case.** If C is pointed (L = {0}), the hypothesis cl N₁ ∩ L = {0} is automatic. The lemma then reduces to Minkowski's theorem: the extreme rays of C lie in Σ ∪ ℝⁿ₊ and on ∂C, hence outside N₁ ⊆ int C.
- **Why the lineality hypothesis is needed.** If cl N₁ contains a lineality direction, the lemma can fail. Support points approaching ±l ∈ L from inside int C can be needed to generate C. This is why Step 3 of the proof of Theorem H first cuts N₀ off from L.

### 2.4 Lemma 2.4 (thin cuts; PROVED)

Let N′ = D_{Q′} be coherent, q ∈ Q′, k ∈ {1, …, n} and s ∈ (0, 1). Put q_s := (1−s)q + sδ_k ∈ Δ and R(s) := N′ ∩ {q_s·h ≤ 0}. Then:
- N′ ∩ {q_s·h > 0} = D_{conv(Q′ ∪ {q_s})} is coherent;
- R(s) decreases to ∅ as s ↓ 0;
- ∫_{R(s)} |h| dμ → 0 and μ(R(s)) → 0.

*Proof.*
- On N′, q·h > 0. If h ∈ R(s), then (1−s) q·h ≤ −s h_k. So R(s) ⊆ {h ∈ N′ : h_k < 0, q·h ≤ (s/(1−s))|h_k|}.
- This set decreases to ∅ as s ↓ 0.
- Dominated convergence, with dominating functions |h| and 1, gives the limits. ∎

*Using a cut.* Let e satisfy P_{Q′}(e) = 0 and e_k < 0, and take q ∈ Q′ with q·e = 0. Then q_s·e = s e_k < 0. So the open cone {q_s·h < 0} contains e and misses the cut model.

### 2.5 Lemma 2.5 (lineality directions have a negative coordinate; PROVED)

If l ≠ 0 and ±l ∈ cl U, then l has a negative coordinate.

*Proof.*
- For k ∈ K′, k·l ≥ 0 and −k·l ≥ 0, so k·l = 0.
- If l ≥ 0 and l ≠ 0, then k·l > 0 for k ∈ K′ ⊆ relint Δ, which is a contradiction. ∎

This is the only place where K′ ⊆ relint Δ (one-sidedness) is used.

### 2.6 Proof of Theorem H

Let X be incoherent. Put Σ := Σ(X), C := cl cone(Σ ∪ ℝⁿ₊), G := hull(X) = int C (Lemma 2.2(b)) and L := C ∩ (−C) ⊆ cl U ∩ (−cl U).

**Step 1: a strict dominator inside the hull.**
- By Lemma 2.2(d), pick π with m(N₀) − m(X) =: d₀ ≫ 0, where N₀ := G ∩ {π·h > 0} = D_{Q₀} and Q₀ := conv(Q_X ∪ {π}).
- Q₀ is compact and convex, and K′ ⊆ Q_X ⊆ Q₀. So N₀ is coherent and N₀ ⊆ G.

**Step 2: cut off the lineality.** (Skip this step if L = {0}, which is automatic when dim K′ = n−1.)
- Fix q_X ∈ Q_X. For s₁ ∈ (0, 1) and k = 1, …, n, put q″_k := (1−s₁)q_X + s₁δ_k, and N₁ := N₀ ∩ ∩_k {q″_k·h > 0}.
- By Lemma 2.4, applied n times, choose s₁ so small that ∫_{N₀∖N₁} |h| dμ < ½ min_i (d₀)_i. Then d₁ := m(N₁) − m(X) ≥ ½ d₀ ≫ 0.
- **cl N₁ ∩ L = {0}.** Let l ∈ L∖0. Then q_X·l = 0, since ±l ∈ C and q_X ∈ C*. By Lemma 2.5, l_k < 0 for some k. So q″_k·l = s₁l_k < 0, while q″_k ≥ 0 on cl N₁. Hence l ∉ cl N₁.
- N₁ = D_{Q₁}, with Q₁ := conv(Q₀ ∪ {q″_k}) ⊇ K′, is a coherent open convex cone with int ℝⁿ₊ ⊆ N₁ ⊆ G ⊆ C.

**Step 3: the added part is non-null.**
- Suppose μ(N₁∖X) = 0. Then d₁ = −m(X∖N₁).
- For k ∈ K′, k·h > 0 on U ⊇ X, so k·d₁ = −∫_{X∖N₁} k·h dμ ≤ 0.
- But d₁ ≫ 0 and k ∈ Δ give k·d₁ > 0. This is a contradiction.
- So N₁∖X is non-null. Pick a ∈ N₁ ∩ supp(N₁∖X); a.e. point of N₁∖X qualifies.

**Step 4: generate a from support points outside N₁.**
- Apply the Generation Lemma 2.3, with C and Σ as above and N₁ from Step 2. Its hypotheses hold: Σ ⊆ C, C = cl cone(Σ ∪ ℝⁿ₊), int ℝⁿ₊ ⊆ N₁ ⊆ C, and cl N₁ ∩ L = {0}.
- So a = Σ_j λ_j e_j + p with e_j ∈ Σ∖N₁, λ_j > 0 and p ≫ 0.
- By conic Carathéodory, r ≤ n. By WT65 W2, r ≤ n−1 can be arranged.
- Any e_j ∈ ℝⁿ₊ is absorbed into p, since λ_j e_j ≥ 0. So every remaining e_j has a negative coordinate.

**Step 5: thin cuts at the boundary support points.**
- For each e_j: either P_{Q₁}(e_j) < 0, or P_{Q₁}(e_j) = 0 (because e_j ∉ N₁ = D_{Q₁}).
  - If P_{Q₁}(e_j) < 0, choose q_j ∈ Q₁ with q_j·e_j < 0. No cut is needed.
  - Otherwise choose q_j ∈ Q₁ with q_j·e_j = 0 (Q₁ is compact), and k(j) with (e_j)_{k(j)} < 0. For s₂ ∈ (0, 1) put q′_j := (1−s₂)q_j + s₂δ_{k(j)}.
- Let N := N₁ ∩ ∩_j {q′_j·h > 0} = D_Q, with Q := conv(Q₁ ∪ {q′_j}).
- By Lemma 2.4, choose s₂ so small that both of the following hold:
  - ∫_{N₁∖N} |h| dμ < min_i (d₁)_i. Then (i) holds.
  - q′_j·a = (1−s₂)q_j·a + s₂a_{k(j)} > 0 for every j. This is possible because q_j·a > 0, as a ∈ N₁ = D_{Q₁}. Hence a ∈ N.

**Step 6: the witness.**
- *a ∈ supp(N∖X).* N is open and contains a. For every open V ∋ a, μ(V ∩ N ∩ (N₁∖X)) > 0, and N ∩ (N₁∖X) ⊆ N∖X, since N ⊆ N₁.
- *e_j ∈ Σ(X∖N).* Let W_j := {q_j·h < 0} or {q′_j·h < 0}, as appropriate. W_j is an open cone containing e_j, disjoint from N. For every open cone V ∋ e_j, V ∩ W_j is an open cone around e_j. Since e_j ∈ Σ, μ(X ∩ V ∩ W_j) > 0, and X ∩ W_j ⊆ X∖N.
- *Residual.* a − Σλ_j e_j = p ≫ 0.
- This is (ii). Lemma 2.1, with A := N∖X and B := X∖N, gives (iii).

**Count of cuts.** At most n in Step 2, and at most r ≤ n in Step 5. ∎

**Corollary H.1 (strict form; PROVED).** For every incoherent X, the set W^≫(X) := {Q ∈ 𝒦(K′) : m(D_Q) − m(X) ≫ 0, Φ_X(Q) > 0} is non-empty and open. Here 𝒦(K′) is the set of compact convex Q with K′ ⊆ Q ⊆ Δ, and Φ_X(Q) := μ((D_Q∖X) ∩ hull(X∖D_Q)). Polytope defenders Q suffice.

## 3. Exact checks of the construction (CHECKED)

`h65py/construct.py` implements §2.6 for rivals that are finite unions of polyhedral cones in three worlds. The density is e^{−|h|₁}, and exact moments come from `es64py/cones.py`. The script:
- computes hull(X) from the extreme rays of the pieces;
- finds π by grid and local search, such that the hull-relative Bayes act has a strict margin;
- samples a gap point a strictly inside N₀ and strictly outside cl X;
- finds λ by linear programming, then rationalises it and **re-verifies it exactly**;
- applies the thin cuts;
- verifies exactly that m(N) − m(X) ≫ 0, that a ∈ N, that every e_j ∉ cl N, and that a − Σλ_j e_j ≫ 0.

Each e_j is an extreme ray of a non-null polyhedral piece, so it lies in Σ(X). Lemma 2.1 then certifies (H).

The search parts (choice of π and a) are searches. A failure to find would refute nothing, and none occurred.

**3.3 What the search taught (NUMERICS, search aid only).**
- The first-pass search (grid plus pattern search on π) failed for 10/30. In every one of those failures the hull-relative strict dominators exist, as Lemma 2.2(d) says. But they are hard to find, for two reasons:
  - their π lies very close to a vertex of Q_X, so N₀ is a thin cut along one face of hull(X);
  - their margins are as small as 3·10⁻⁸.
- What finds them is the proof of Lemma 2.2(d) made computational:
  - solve the fuzzy relaxation "max t s.t. Σ x_c m(c∖X) − Σ y_c m(c∩X) ≥ t𝟙" over small cones c;
  - take its dual weights, which give a threshold (G-Bayes) set;
  - refine.
- For hole #7, for example: the fuzzy LP value is t = 4.9·10⁻⁶ > 0, and Nelder–Mead from the dual gives margin 7.3·10⁻⁶.

This mirrors REF64_es R1's "thin shell" mechanism. It is also why ES64's searches over U-Bayes acts, which sampled π away from these vertices and did not relativise to the hull, missed them.

## 4. The question WT65 left open

> Can a witness in 𝒮(X) that ties X in some coordinate always be replaced by one with a strict margin in every coordinate?

**Answer: yes (PROVED), in the strongest form.**
- By Theorem H, every incoherent X has a witnessing defender with m(N) − m(X) ≫ 0, whether or not tied witnesses exist.
- So (H) ⟺ W^≫(X) ≠ ∅ for every incoherent X. Both sides are true, and W^≫(X) is open (Cor H.1).

Two cautions.
- The replacement is *not* obtained by perturbing a given tied witness. Theorem H builds a strict witness from scratch.
- WT65's examples C5 and C6 still stand: Φ_X is not upper semicontinuous. A maximising sequence of witnesses can still converge to a non-witness. The theorem does not need limits.

## 5. Scope (auditor's corrections, carried forward)

- **Fixed domain.** Theorem H is about a fixed evaluable domain U = D_{K′}. "Universal" means: every coherent model *on U*. Coverage claims for a target K need K′ ⊆ relint K, with (LF) as a property of U (REF64_es §2.4).
- **What the framework does and does not show.** With (H) proved, the binding framework admits one ranking whose undominated models are exactly the coherent ones. This is a **representation of coherence through dominance**.
  - Because Δ(𝒩) refuses comparisons according to whether a record attacks a coherent model, it is **not an independent accuracy-based justification** of coherence (REF64_es §5.3(1); AUDIT_r65_message).
  - The formal theorem and this philosophical limitation should be reported together, as the auditor asks.
- **(Add).** Nothing here bears on (Add). Δ(𝒩) still violates (Add) (REF64_es §5.3(3)). Whether the strengthened framework (G) + (IB) + (TC) + (Add) admits a cover is untouched by Theorem H.
- **Refereeing.** Theorem H is new and not yet refereed.
  - Its delicate points are Lemma 2.3 (Steps 2–3) and the relative Lemma 5.1 (Lemma 2.2(d)).
  - The latter is ES64's refereed proof with U replaced by G. The only properties of U it used are "open, non-empty cone". G has both.
  - I recommend a referee check of Lemma 2.3 and of Step 2 (the lineality cut) in particular.
